## 一、角色及关键术语定义

| 角色/术语  | 简称  | 职责/说明          |
| :----- | :-: | :------------- |
| 编排长    |  A  | 统筹负责整个编排组的工作   |
| 手工成绩员  |  B  | 负责手工记录比赛成绩     |
| 电子成绩员  |  C  | 负责电子表格成绩记录与维护  |
| 出单员    |  Z  | 负责打印交换名单和成绩单   |
| D-Day  |  -  | 正式比赛日          |
| 编排组沟通群 |  -  | 编排人员工作沟通交流的微信群 |

## 二、赛前准备工作

| 时间节点 | 责任人 | 工作内容                                                                                                                                   |
| :--: | :-: | :------------------------------------------------------------------------------------------------------------------------------------- |
| D-8前 |  A  | 建立编排组沟通群，同步赛制、赛程、参赛人员等核心信息                                                                                                             |
| D-5前 |  C  | 完成电子表格 V1 版本，发送给 Z 并确认接收                                                                                                               |
| D-3前 |  Z  | 完成电子表格 V1 总体试用，核对以下信息：  <br>• 场地信息  <br>• 比赛时间  <br>• 小组赛及淘汰赛对阵人员名单  <br>• 交换名单的比赛项目  <br>• 记分表格式（含胜方/裁判签名、单页打印适配性、上下对称排版）  <br>• 其他事项 |
| D-3前 |  Z  | 将复核结果及问题反馈给 C                                                                                                                          |
| D-1前 |  C  | 修复问题后，将电子表格 V2 发送给 Z                                                                                                                   |
| D-1  |  Z  | 试用 V2 表格，确认无误后打印第一阶段可提前打印的记分单  <br>_(如无打印设备，可交由 A 或 C 协助)_                                                                             |
| D-1  | A/C | 足额打印秩序册、节目单等材料 _(具体份数待确认)_                                                                                                             |

## 三、比赛当天工作

### 需携带的设备

| 责任人   | 设备清单                 |
| ----- | -------------------- |
| **A** | 打印机、备用硒鼓、足量空白 A4 纸、笔 |
| **B** | 至少两种颜色的笔、透明胶带        |
| **C** | 可连接打印机的笔记本电脑、笔       |
| **Z** | 可连接打印机的笔记本电脑、笔       |

### 座位安排

- **Z** 坐中间，**B/C** 分坐两侧
- **B** 靠近检录处一侧，便于收发材料

### 比赛时分工

| 责任人   | 核心职责                                                                                                 |
| ----- | ---------------------------------------------------------------------------------------------------- |
| **A** | 统筹指导编排组工作，实时掌握比赛进度                                                                                   |
| **B** | • 手工记录成绩，将名次同步给 **Z**  <br>• 阶段性与 **C** 核对成绩与名次表  <br>• 公示成绩记录  <br>• 收发交换名单与记分单                     |
| **C** | • 维护电子成绩表格，阶段性与 **B** 核对成绩  <br>• 核对 **Z** 产出的记分单和交换名单  <br>• 产出名次表交 **B** 核对  <br>• 产出电子成绩单，整理纸质记分表 |
| **D** | • 录入各阶段名次，及时产出交换名单和记分单  <br>• 将产出材料交 **C** 复核 → **B** 送至检录处  <br>• 手工更新出单表，掌握总体进度及优先出单场次             |
